How this shop runs

You own it. You do not have to operate it. The public site stays this simple on purpose.

What you do

  1. Edit config.js. Brand, price, email, payment link.
  2. Push the folder to GitHub.
  3. Import it in Vercel. It is a static site. No build command.
  4. Read the Friday note if an agent wants to change the price.

What you do not do

  • You do not write the weekly page.
  • You do not answer routine mail. Support does.
  • You do not approve a refund inside the published window.
  • You do approve a new price, a new supplier, or a legal change.
